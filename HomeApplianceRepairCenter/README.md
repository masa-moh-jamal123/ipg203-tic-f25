# Home Appliance Repair Center

Console application for TIC_IPG203_F25 Assignment 1.

## IMPORTANT - Visual Studio 2022 compatibility
This edition targets **.NET Framework 4.8** and uses the classic Visual Studio project format.
It does **not** require the `dotnet` command or the .NET 8 SDK.

### Run
1. Open `HomeApplianceRepairCenter.sln` with Visual Studio 2022.
2. Build > Build Solution.
3. Press Ctrl+F5.

The project demonstrates Interface, Abstract Class, Inheritance, Polymorphism, Encapsulation, Delegates & Events, and Static class/member usage.
